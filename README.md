# Zero - ゲーマー特化軽量化ツール

Windows専用のゲーマー向けシステム軽量化ツールです。メモリ解放、不要プロセスの終了、サービス無効化を行い、ゲームプレイ中のパフォーマンスを向上させます。

## 機能

- **メモリ解放**: プロセスのワーキングセットを空にしてメモリを解放
- **不要プロセス終了**: ゲームプレイに不要なブラウザやアプリを終了
- **サービス無効化**: バックグラウンドサービスを一時停止
- **ネットワーク最適化**: レイテンシ（ping）を低減するTCP/レジストリ設定
- **回線ブースト**: 悪い回線向けの強化設定（CTCP輻輳制御、NIC省電力無効化、Game Mode強制、Delivery Optimization停止）
- **pingテスト**: 1.1.1.1へのpingで平均レイテンシを計測

## ビルド方法

```bash
cargo build --release
```

## 実行方法

```bash
.\target\release\FARST.exe
```

## 使用方法

プログラムを起動すると、以下のメニューが表示されます：

1. **システムステータス表示**: 現在のメモリ使用状況とプロセス一覧を表示
2. **メモリ解放**: プロセスのメモリを解放
3. **不要プロセス終了**: 不要なプロセスを終了
4. **サービス無効化**: 不要なサービスを停止
5. **全部実行**: すべての軽量化処理（ネットワーク最適化含む）を一括実行
6. **ネットワーク最適化**: レイテンシ低減のためのTCP/IP・レジストリ設定を適用
7. **pingテスト**: 1.1.1.1へのpingで平均レイテンシを表示
0. **終了**: プログラムを終了

## 注意事項

- このツールはシステム権限で実行することを推奨します
- 一部のプロセスやサービスは終了/停止できない場合があります
- 必要なプロセス（System, svchost.exeなど）は終了対象外です
- 本ツールの使用は自己責任でお願いします

## ターゲットプロセス

以下のプロセスが不要プロセスとして終了対象になります：
- chrome.exe, firefox.exe, msedge.exe
- slack.exe, discord.exe, teams.exe
- zoom.exe, spotify.exe
- onedrive.exe, skype.exe, thunderbird.exe

## ターゲットサービス

以下のサービスが停止対象になります：
- XblGameSave, XboxNetApiSvc, XboxGipSvc
- SysMain, WSearch, DiagTrack
